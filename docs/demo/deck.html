01 · The challenge

Earth is always changing. Which changes are real?

Thousands of variables, noisy records, and neighbouring regions that can move in opposite directions. Students need a way to go from a simple question to a statistically honest answer.

1 · Identify

19 Earth-science variables in plain language — temperature, rain, soil moisture, aerosols, ozone, sea ice, NDVI… with the mission behind each.

2 · Acquire

Live NASA POWER data for any country, region or drawn box — every grid cell inside the border, area-weighted.

3 · Visualise

45-year monthly time series (1981–2025): annual trend, monthly record, deseasonalised anomalies, seasonal shift.

4 · Test

Rate of change + significance: Mann-Kendall, Sen's slope with 95% CI, autocorrelation-corrected regression, Seasonal Kendall.

The four challenge requirements — each one built and working in the app.

02 · How it works

From a question to a tested answer in seconds

  • Ask — “Is precipitation decreasing in Jordan?” A parser picks the variable and the place.
  • Fetch — one NASA POWER request per grid cell (MERRA-2 / CERES), area-weighted inside the real country border; cached on the device.
  • Test — trend tests on annual values and on deseasonalised monthly anomalies, with an AR(1) effective-sample-size correction.
  • Explain — one plain sentence, the 95% confidence interval, the p-value, and how many years would be needed to detect the trend.

03 · A result, read honestly

Is Jordan drying? Not yet provably.

−1.90 mm/yr per decade

Yearly rainfall over Jordan's 28 NASA POWER grid cells, 1981–2025.

  • 95% confidence interval −8.93 … +5.78 — it includes zero.
  • Mann-Kendall p = 0.63 → ◇ not significant.
  • A trend this size would need ≈ 94 years of data to detect; the record has 45.

EARTHSCOPE says so plainly — and never shows significance by colour alone (▲ ▼ ◇ + label + line style).

04 · Same variable, different places

Compare regions on one axis

▲ Cameroon is warming by about 0.36 °C per decade — significant (p < 0.001).

▲ DR Congo +0.36 °C per decade — significant.

◇ Tanzania +0.04 °C — not significant (p = 0.41).

“Opposite trends” are only claimed when both regions are significant with opposite signs. Our own demo Sahel vs Iberia is phrased as a question — the data answer it: no.

06 · Built to be trusted

Real NASA data. Honest statistics. Open source.

  • Real data only — NASA POWER (MERRA-2 / CERES), GIBS, GISTEMP, MODIS NDVI (ORNL DAAC), NSIDC Sea Ice Index. Every series shows its source and retrieval date; no numbers are fabricated.
  • Tested statistics — 697 automated tests; the statistics engine is cross-checked against SciPy and pymannkendall.
  • One significance rule — p < 0.05 for one series; FDR q < 0.05 for maps.
  • For students — plain-language sentences, guided demos that open instantly, report export (PDF / CSV / JSON).
